# 野球モンスターズ

泰志が毎日の「素振り10回」「シャドーピッチング10回」を、
**泰志 VS 野球モンスター**の試合として記録していくアプリです。

- サーバーもログインも不要。記録はスマホ／iPadの中（localStorage）だけに保存されます
- iPhone・iPadのホーム画面に追加すると、アプリのように開けます（PWA）
- HTML＋CSS＋ふつうのJavaScriptだけ。むずかしいライブラリは使っていません

---

## 1. ファイルの置き方

この10個を、**ぜんぶ同じフォルダ**に入れてください（入れ子にしない）。

```
yakyu-monsters/
├── index.html            ← アプリの入口
├── styles.css            ← 見た目
├── app.js                ← ゲームのしくみ
├── players.js            ← 選手データ（ここを足していく）
├── monsters.js           ← モンスターデータ
├── manifest.webmanifest  ← ホーム画面に追加するための設定
├── sw.js                 ← オフライン用
├── icon-192.png          ← ホーム画面アイコン（小）
├── icon-512.png          ← ホーム画面アイコン（大）
└── README.md             ← このファイル
```

### 泰志の写真を出したいとき

公開サイトに個人の写真を置かないため、初期状態では**写真なし**（絵文字とボール）です。
家の中だけで使う版で写真を出すときは、次の2つだけです。

1. `taishi.png`（正方形・顔まわり）と `taishi-card.png`（カード全体）をこのフォルダに置く
2. `app.js` の上のほうにある2行を書きかえる

```js
const TAISHI_FACE = 'taishi.png';
const TAISHI_CARD = 'taishi-card.png';
```

これでスタート画面がカード、試合画面と結果画面が泰志の顔アイコンになります。
`sw.js` の `FILES` にも `'./taishi.png', './taishi-card.png'` を足しておくと、
オフラインでも写真が出ます。

> 写真を出したファイルをGitHubに上げると、URLを知っている人は誰でも見られる状態に
> なります。写真入りは「Macの中だけ」で使うのがおすすめです。

## 2. パソコン（Mac）で動かして確認する

`index.html` をダブルクリックでも画面は出ますが、
「ホーム画面に追加」やオフライン機能は **http:// で開いたとき**しか動きません。
下の方法で確認するのがおすすめです。

1. Macで「ターミナル」を開く
2. 次の1行を貼って Enter（フォルダの場所は自分の場所に合わせる）

```bash
cd ~/Desktop/yakyu/yakyu-monsters && python3 -m http.server 8000
```

3. ブラウザで `http://localhost:8000` を開く
4. 止めるときはターミナルで `Control + C`

> スマホと同じ見え方で確認したいときは、Chromeで右クリック →「検証」→
> 左上のスマホのアイコンを押すと、iPhoneの画面サイズになります。

## 3. 無料で公開する（GitHub Pages）

ブラウザだけで完結します。所要10分ほど。

1. https://github.com/ にログイン
2. 右上の「＋」→ **New repository**
3. Repository name に `yakyu-monsters` と入力 → **Public** を選ぶ → **Create repository**
4. 次の画面で **uploading an existing file** のリンクを押す
5. `yakyu-monsters` フォルダの中身（10個のファイル）を**すべてまとめてドラッグ＆ドロップ**
   - ※フォルダごとではなく、**中のファイルを選んで**入れるのがコツです
6. 下の **Commit changes** を押す
7. 上のメニューの **Settings** → 左の **Pages** を開く
8. Source を「Deploy from a branch」、Branch を **main** ／ **/(root)** にして **Save**
9. 1〜2分待ってページを再読み込みすると、上にURLが出ます

```
https://＜あなたのGitHubのID＞.github.io/yakyu-monsters/
```

このURLを、泰志が使うiPhone／iPadで開きます。

> 直したファイルを差しかえるときは、同じリポジトリで
> **Add file → Upload files** から同じ名前のファイルを入れて Commit すればOKです。

## 4. iPhone・iPadのホーム画面に追加する

1. **Safari**で上のURLを開く（ChromeではなくSafariで）
2. 下（iPadは上）の **共有ボタン**（□に↑）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」**
4. 名前が「野球モンスターズ」になっていることを確認して **追加**

ホーム画面のアイコンから開くと、上下のブラウザのバーが消えて、
アプリのような全画面で使えます。

## 5. 遊び方（ルール）

| できごと | 泰志 | モンスター |
|---|---:|---:|
| 素振り＋シャドーピッチング 両方 | 2点 | 1点 |
| どちらか1つ | 1点 | 1点 |
| 記録しなかった日（7日終了時） | 0点 | 1点 |

- 1試合は**7日間**。「ゲームスタート！」を押した日が第1日目です
- 毎日：チャレンジを選ぶ → 真似する選手を選ぶ → 10回やる → **できた！** →
  最後に **今日の結果を確定！**
- 「確定！」を押したときに、その日の点数が入り、選手カードをGETできます
- 記録を入れたり直したりできるのは **今日と前日だけ**
- 7日終わって同点なら **延長戦**。差がつくまで続きます
- 試合に勝つと、そのモンスターを**モンスター図鑑にGET**

## 6. 選手を増やす

### アプリの中から増やす（泰志が自分でできる）
選手えらびの画面 →「➕ その他の選手を追加」→ 名前とチームを入れるだけ。
打撃チャレンジから追加した選手は「打者」、投球チャレンジからなら「投手」になります。

### ファイルで増やす（お父さんの作業）
`players.js` の最後のほうに、1行足すだけです。

```js
{ id: "sasaki_2026", name: "佐々木朗希", team: "ロサンゼルス・ドジャース",
  type: "pitcher", wbcYears: [2026], group: "wbc" },
```

- `id` は他とかぶらない英数字
- `type` は `"batter"`（打者）／`"pitcher"`（投手）／`"both"`（両方）
- `wbcYears` に大会の年を入れると、その大会のタブに出ます
- 大会タブそのものを足したいときは、`players.js` 最後の `WBC_YEARS` に年を足す

モンスターを足すときは `monsters.js` に同じように1行足します。

## 7. ファイルを直したのにスマホが古いまま、のとき

オフライン用のしくみ（Service Worker）が、前のファイルを覚えているためです。
`sw.js` の1行目あたりにある

```js
const CACHE = 'baseball-monsters-v1';
```

の **v1 を v2、v3 …と増やして**アップロードし直すと、新しいものが届きます。

---

## 8. 記録の保存について（だいじ）

- 記録は、そのスマホ／iPadの**ブラウザの中だけ**に保存されます
- 別の端末とは同期しません。**Safariの履歴・サイトデータを全部消すと記録も消えます**
- ファイルを差しかえても記録は残ります（保存の名前を変えなければOK）

---

## 9. 仕様書からの変更点（1か所だけ）

延長戦で「泰志0点・モンスター1点 → モンスターの勝ち」という決まりがありますが、
**0点で確定するボタンはあえて作っていません**。
「やらなかったことを押させない」というこのアプリの方針と、
「延長では未記録の日を負け扱いにしない」という決まりを両立させるためです。
そのため延長戦は、泰志が2点とるか、続けるか、のどちらかになります。
（0点で確定した日があった場合の計算はプログラム側に入っているので、
 あとからボタンを足せば仕様どおりに動きます）
